# Mudancas Implementadas - 04/04/2026

## Objetivo
Implementar as funcionalidades priorizadas na analise anterior, comecando por:
1. Pipeline real de upload e processamento
2. Dashboard com dados reais
3. Inbox de processamento

Tambem foram avancadas funcionalidades seguintes de autenticacao, chat com IA contextual e notificacoes automaticas.

## Funcionalidades Entregues

### 1) Pipeline real de Upload -> Processamento IA -> Prazos
- Criada mutacao `documents.uploadAndProcess` no backend.
- Fluxo implementado:
  - cria ou reutiliza processo por numero
  - faz upload do PDF para storage
  - cria documento com status `processing`
  - processa PDF com LLM
  - salva resumo, entidades, texto extraido
  - cria prazos automaticamente
  - conclui documento como `processed`
  - em falha, marca documento como `failed`

Arquivos:
- `server/routers.ts`
- `server/services/documentProcessor.ts`
- `server/db.ts`

### 2) Dashboard com dados reais
- Dashboard agora consome dados reais via tRPC:
  - `deadlines.listMine`
  - `documents.listMine`
  - `processes.list`
- Cards de estatistica e grafico semanal passaram a ser calculados com dados do banco.

Arquivos:
- `client/src/pages/Dashboard.tsx`
- `server/routers.ts`
- `server/db.ts`

### 3) Inbox de processamento de documentos
- Pagina de upload passou a usar mutacao real `uploadAndProcess`.
- Conversao de arquivo para base64 no cliente para envio unico.
- Inbox agora exibe lista real de documentos do usuario com status:
  - `processed`
  - `processing`
  - `failed`

Arquivos:
- `client/src/pages/Upload.tsx`
- `server/routers.ts`

Arquivos:
- `server/services/notificationScheduler.ts`
- `server/_core/index.ts`
